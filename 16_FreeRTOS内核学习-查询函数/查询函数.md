# 查询函数学习

主要是 **任务优先级、任务状态、任务句柄、系统统计、调试诊断** 相关函数。

## 通用前提

很多任务查询类 API 都需要在 `FreeRTOSConfig.h` 中打开对应宏，例如：

```c
#define INCLUDE_uxTaskPriorityGet              1
#define INCLUDE_vTaskPrioritySet               1
#define INCLUDE_xTaskGetCurrentTaskHandle      1
#define INCLUDE_xTaskGetHandle                 1
#define INCLUDE_xTaskGetIdleTaskHandle         1
#define INCLUDE_uxTaskGetStackHighWaterMark    1
#define INCLUDE_eTaskGetState                  1
#define INCLUDE_pcTaskGetTaskName              1
#define INCLUDE_xTaskGetSchedulerState         1

#define configUSE_TRACE_FACILITY               1
#define configUSE_STATS_FORMATTING_FUNCTIONS   1
```

注意：

- 大多数没有 `FromISR` 后缀的函数**不要在中断中调用**。
- 很多函数参数中的 `TaskHandle_t xTask` 如果传入 `NULL`，表示查询当前任务。
- `vTaskList()`、`vTaskGetRunTimeStats()` 等统计函数开销较大，更适合调试，不建议高频运行在正式业务逻辑中。

---

## 1. `uxTaskPriorityGet()`

**作用：** 获取某个任务当前优先级。

```c
UBaseType_t uxTaskPriorityGet( TaskHandle_t xTask );
```

**用法案例：**

```c
UBaseType_t prio;

prio = uxTaskPriorityGet( NULL );   // 获取当前任务优先级
```

如果要获取指定任务：

```c
prio = uxTaskPriorityGet( xLedTaskHandle );
```

**使用条件：**

```c
#define INCLUDE_uxTaskPriorityGet  1
```

**注意：**

- 返回值范围通常是 `0 ~ configMAX_PRIORITIES - 1`。
- 数值越大，优先级越高。

---

## 2. `vTaskPrioritySet()`

**作用：** 修改任务优先级。

```c
void vTaskPrioritySet( TaskHandle_t xTask, UBaseType_t uxNewPriority );
```

**用法案例：**

```c
vTaskPrioritySet( xLedTaskHandle, 3 );
```

修改当前任务优先级：

```c
vTaskPrioritySet( NULL, 2 );
```

**使用条件：**

```c
#define INCLUDE_vTaskPrioritySet  1
```

**注意：**

- 如果把某个任务优先级调高，可能会立即触发任务切换。
- 新优先级不能大于等于 `configMAX_PRIORITIES`。

---

## 3. `uxTaskGetSystemState()`

**作用：** 获取系统中所有任务的状态信息。

```c
UBaseType_t uxTaskGetSystemState(
    TaskStatus_t * const pxTaskStatusArray,
    const UBaseType_t uxArraySize,
    configRUN_TIME_COUNTER_TYPE * const pulTotalRunTime
);
```

**用法案例：**

```c
TaskStatus_t taskArray[10];
UBaseType_t taskCount;
uint32_t totalRunTime;

taskCount = uxTaskGetSystemState(
    taskArray,
    10,
    &totalRunTime
);
```

之后可以遍历：

```c
for( UBaseType_t i = 0; i < taskCount; i++ )
{
    printf("Task: %s, Priority: %lu\r\n",
           taskArray[i].pcTaskName,
           taskArray[i].uxCurrentPriority);
}
```

**使用条件：**

```c
#define configUSE_TRACE_FACILITY  1
```

如果需要运行时间统计，还要配置：

```c
#define configGENERATE_RUN_TIME_STATS  1
```

**注意：**

- `pxTaskStatusArray` 数组要足够大，通常先用 `uxTaskGetNumberOfTasks()` 获取任务数量。
- 该函数会遍历任务控制块，适合调试、监控，不建议频繁调用。

---

## 4. `vTaskGetInfo()`

**作用：** 获取单个任务的详细状态信息。

```c
void vTaskGetInfo(
    TaskHandle_t xTask,
    TaskStatus_t *pxTaskStatus,
    BaseType_t xGetFreeStackSpace,
    eTaskState eState
);
```

**用法案例：**

```c
TaskStatus_t info;

vTaskGetInfo(
    xLedTaskHandle,
    &info,
    pdTRUE,       // 是否获取栈剩余最小值
    eInvalid      // 自动获取任务状态
);

printf("Name: %s\r\n", info.pcTaskName);
printf("Priority: %lu\r\n", info.uxCurrentPriority);
printf("Stack high water mark: %lu\r\n", info.usStackHighWaterMark);
```

**使用条件：**

```c
#define configUSE_TRACE_FACILITY  1
```

如果 `xGetFreeStackSpace` 为 `pdTRUE`，还依赖栈水位检测相关配置。

**注意：**

- `xGetFreeStackSpace = pdTRUE` 会扫描栈空间，开销比普通查询更大。
- `eState` 如果传 `eInvalid`，函数会自己获取任务状态。

---

## 5. `xTaskGetApplicationTaskTag()`

**作用：** 获取任务的应用层 Tag。

```c
TaskHookFunction_t xTaskGetApplicationTaskTag( TaskHandle_t xTask );
```

**用法案例：**

```c
TaskHookFunction_t tag;

tag = xTaskGetApplicationTaskTag( xLedTaskHandle );
```

**使用条件：**

```c
#define configUSE_APPLICATION_TASK_TAG  1
```

**注意：**

- 这个 Tag 本质上是一个任务钩子函数指针 `TaskHookFunction_t`。
- 实际项目中不算特别常用，更多用于 trace、调试、用户自定义扩展。

---

## 6. `vTaskSetApplicationTaskTag()`

**作用：** 设置任务的应用层 Tag。

```c
void vTaskSetApplicationTaskTag(
    TaskHandle_t xTask,
    TaskHookFunction_t pxHookFunction
);
```

**用法案例：**

```c
static BaseType_t MyTaskHook( void *arg )
{
    return 0;
}

vTaskSetApplicationTaskTag( xLedTaskHandle, MyTaskHook );
```

**使用条件：**

```c
#define configUSE_APPLICATION_TASK_TAG  1
```

**注意：**

- 一般用于内核 trace hook 或用户自定义调试逻辑。
- 普通任务业务开发中使用较少。

## 7. `xTaskGetCurrentTaskHandle()`

**作用：** 获取当前正在运行任务的句柄。

```c
TaskHandle_t xTaskGetCurrentTaskHandle( void );
```

**用法案例：**

```c
TaskHandle_t currentTask;

currentTask = xTaskGetCurrentTaskHandle();
```

**使用条件：**

```c
#define INCLUDE_xTaskGetCurrentTaskHandle  1
```

**注意：**

- 常用于任务内部保存自己的句柄。
- 不建议在中断中调用。

---

## 8. `xTaskGetHandle()`

**作用：** 通过任务名获取任务句柄。

```c
TaskHandle_t xTaskGetHandle( const char *pcNameToQuery );
```

**用法案例：**

```c
TaskHandle_t handle;

handle = xTaskGetHandle( "LED_Task" );

if( handle != NULL )
{
    vTaskPrioritySet( handle, 3 );
}
```

**使用条件：**

```c
#define INCLUDE_xTaskGetHandle  1
```

**注意：**

- 任务名需要唯一，否则可能获取到同名任务中的某一个。
- 该函数会遍历任务列表，效率不如直接保存任务句柄。
- 更推荐在 `xTaskCreate()` 时保存句柄：

```c
xTaskCreate( LedTask, "LED_Task", 128, NULL, 2, &xLedTaskHandle );
```

---

## 9. `xTaskGetIdleTaskHandle()`

**作用：** 获取空闲任务的句柄。

```c
TaskHandle_t xTaskGetIdleTaskHandle( void );
```

**用法案例：**

```c
TaskHandle_t idleHandle;

idleHandle = xTaskGetIdleTaskHandle();
```

**使用条件：**

```c
#define INCLUDE_xTaskGetIdleTaskHandle  1
```

**注意：**

- 调度器启动后才有空闲任务。
- 一般用于调试、统计、监控，不建议随意操作空闲任务优先级或状态。

## 10. `uxTaskGetStackHighWaterMark()`

**作用：** 获取任务栈历史剩余最小值，也就是栈的 High Water Mark。

```c
UBaseType_t uxTaskGetStackHighWaterMark( TaskHandle_t xTask );
```

**用法案例：**

```c
UBaseType_t stackRemain;

stackRemain = uxTaskGetStackHighWaterMark( xLedTaskHandle );

printf("LED task stack remain: %lu\r\n", stackRemain);
```

查询当前任务：

```c
stackRemain = uxTaskGetStackHighWaterMark( NULL );
```

**使用条件：**

```c
#define INCLUDE_uxTaskGetStackHighWaterMark  1
```

**注意：**

- 返回值单位通常是 `StackType_t`，不是字节。
- 如果 `sizeof(StackType_t) == 4`，返回 `100` 表示大约还有 `400` 字节历史未使用。
- 这是“历史最小剩余栈”，不是当前瞬时剩余栈。
- 对 STM32 这类栈向下增长的平台，它通常从栈低地址开始扫描连续的 `0xA5` 填充值。

---

## 11. `eTaskGetState()`

**作用：** 获取任务当前状态。

```c
eTaskState eTaskGetState( TaskHandle_t xTask );
```

**返回值常见类型：**

```c
eRunning
eReady
eBlocked
eSuspended
eDeleted
eInvalid
```

**用法案例：**

```c
eTaskState state;

state = eTaskGetState( xLedTaskHandle );

if( state == eBlocked )
{
    printf("LED task is blocked\r\n");
}
```

**使用条件：**

```c
#define INCLUDE_eTaskGetState  1
```

**注意：**

- `eRunning` 表示正在运行。
- `eReady` 表示就绪，等待调度。
- `eBlocked` 通常表示在延时、等待队列、等待信号量等。
- `eSuspended` 表示任务被挂起。

## 12. `pcTaskGetName()`

**作用：** 获取任务名字符串。

```c
char *pcTaskGetName( TaskHandle_t xTaskToQuery );
```

**用法案例：**

```c
char *name;

name = pcTaskGetName( xLedTaskHandle );

printf("Task name: %s\r\n", name);
```

查询当前任务：

```c
printf("Current task: %s\r\n", pcTaskGetName( NULL ));
```

**使用条件：**

```c
#define INCLUDE_pcTaskGetTaskName  1
```

**注意：**

- 任务名来自 `xTaskCreate()` 的第二个参数。
- 任务名最大长度受 `configMAX_TASK_NAME_LEN` 限制。

## 13. `xTaskGetTickCount()`

**作用：** 获取系统节拍计数值。

```c
TickType_t xTaskGetTickCount( void );
```

**用法案例：**

```c
TickType_t now;

now = xTaskGetTickCount();
```

计算时间间隔：

```c
TickType_t start = xTaskGetTickCount();

vTaskDelay( pdMS_TO_TICKS(1000) );

TickType_t elapsed = xTaskGetTickCount() - start;
```

**使用条件：**

一般无需特殊宏。

**注意：**

- 返回的是系统 tick 数，不是毫秒。
- 可以用 `pdMS_TO_TICKS(ms)` 进行换算。
- tick 计数会溢出，使用差值计算通常是安全的：

```c
if( xTaskGetTickCount() - lastWakeTime >= pdMS_TO_TICKS(1000) )
{
    lastWakeTime = xTaskGetTickCount();
}
```

---

## 14. `xTaskGetTickCountFromISR()`

**作用：** 在中断中获取系统节拍计数值。

```c
TickType_t xTaskGetTickCountFromISR( void );
```

**用法案例：**

```c
void EXTI_IRQHandler(void)
{
    TickType_t tick;

    tick = xTaskGetTickCountFromISR();

    // 记录中断发生时间
}
```

**使用条件：**

一般无需特殊宏，但要遵守 FreeRTOS 的中断优先级规则。

**注意：**

- ISR 中应使用带 `FromISR` 后缀的 API。
- 在 STM32 Cortex-M 上，调用 FreeRTOS ISR API 的中断优先级不能高于 `configMAX_SYSCALL_INTERRUPT_PRIORITY` 所允许的范围。

---

## 15. `xTaskGetSchedulerState()`

**作用：** 获取任务调度器状态。

```c
BaseType_t xTaskGetSchedulerState( void );
```

**返回值：**

```c
taskSCHEDULER_NOT_STARTED
taskSCHEDULER_RUNNING
taskSCHEDULER_SUSPENDED
```

**用法案例：**

```c
BaseType_t state;

state = xTaskGetSchedulerState();

if( state == taskSCHEDULER_RUNNING )
{
    printf("Scheduler is running\r\n");
}
```

**使用条件：**

```c
#define INCLUDE_xTaskGetSchedulerState  1
```

**注意：**

- 可以用来判断调度器是否已经启动。
- 如果调度器被 `vTaskSuspendAll()` 暂停，会返回 `taskSCHEDULER_SUSPENDED`。

## 17. `vTaskList()`

**作用：** 以表格字符串形式获取所有任务的信息。

```c
void vTaskList( char *pcWriteBuffer );
```

**用法案例：**

```c
char buffer[512];

vTaskList( buffer );

printf("Name          State Priority Stack Num\r\n");
printf("%s\r\n", buffer);
```

输出类似：

```text
LED_Task      R     2        120   1
Idle          R     0        80    2
```

**使用条件：**

```c
#define configUSE_TRACE_FACILITY              1
#define configUSE_STATS_FORMATTING_FUNCTIONS  1
```

**注意：**

- `pcWriteBuffer` 必须足够大。
- 这是调试函数，内部格式化字符串，开销较大。
- 不建议在资源紧张的正式产品中频繁调用。

---

## 18. `vTaskGetRunTimeStats()`

**作用：** 获取各个任务运行时间统计信息。

```c
void vTaskGetRunTimeStats( char *pcWriteBuffer );
```

**用法案例：**

```c
char buffer[512];

vTaskGetRunTimeStats( buffer );

printf("%s\r\n", buffer);
```

输出类似：

```text
LED_Task      1000      25%
Comm_Task     2000      50%
Idle          1000      25%
```

**使用条件：**

```c
#define configUSE_TRACE_FACILITY              1
#define configUSE_STATS_FORMATTING_FUNCTIONS  1
#define configGENERATE_RUN_TIME_STATS         1
```

还需要提供运行时间计数器相关宏，例如：

```c
#define portCONFIGURE_TIMER_FOR_RUN_TIME_STATS()
#define portGET_RUN_TIME_COUNTER_VALUE()
```

**注意：**

- 需要一个比系统 tick 更高分辨率的计数器，例如硬件定时器。
- 常用于分析 CPU 占用率。
- 不建议频繁调用。

## 19. `vTaskSetThreadLocalStoragePointer()`

你图里写的是 `SetThreadLocalStoragePointer()`，FreeRTOS 中完整函数名通常是：

```c
void vTaskSetThreadLocalStoragePointer(
    TaskHandle_t xTaskToSet,
    BaseType_t xIndex,
    void *pvValue
);
```

**作用：** 给某个任务设置线程本地存储指针，也就是每个任务独有的用户数据指针。

**用法案例：**

```c
typedef struct
{
    uint32_t id;
    char name[16];
} TaskUserData_t;

TaskUserData_t ledData = {
    .id = 1,
    .name = "LED"
};

vTaskSetThreadLocalStoragePointer(
    xLedTaskHandle,
    0,
    &ledData
);
```

**使用条件：**

```c
#define configNUM_THREAD_LOCAL_STORAGE_POINTERS  1
```

如果需要多个指针：

```c
#define configNUM_THREAD_LOCAL_STORAGE_POINTERS  3
```

**注意：**

- `xIndex` 范围是 `0 ~ configNUM_THREAD_LOCAL_STORAGE_POINTERS - 1`。
- 适合保存每个任务独有的上下文，例如日志对象、任务私有配置、状态结构体等。
- 指针指向的数据生命周期要足够长，不能指向已经失效的局部变量。

---

## 20. `pvTaskGetThreadLocalStoragePointer()`

你图里写的是 `GetThreadLocalStoragePointer()`，FreeRTOS 中完整函数名通常是：

```c
void *pvTaskGetThreadLocalStoragePointer(
    TaskHandle_t xTaskToQuery,
    BaseType_t xIndex
);
```

**作用：** 获取某个任务的线程本地存储指针。

**用法案例：**

```c
TaskUserData_t *data;

data = pvTaskGetThreadLocalStoragePointer(
    xLedTaskHandle,
    0
);

if( data != NULL )
{
    printf("Task ID: %lu, name: %s\r\n", data->id, data->name);
}
```

获取当前任务的私有数据：

```c
TaskUserData_t *data;

data = pvTaskGetThreadLocalStoragePointer( NULL, 0 );
```

**使用条件：**

```c
#define configNUM_THREAD_LOCAL_STORAGE_POINTERS  1
```

**注意：**

- 和 `vTaskSetThreadLocalStoragePointer()` 配套使用。
- 适合封装任务私有上下文。
- 如果任务删除时需要释放这些指针指向的资源，要额外考虑清理逻辑。
