# 事件标志组

## 1. 简介

1. **作用**：用于任务间多个事件的同步
2. 通过一个16位或者32位的整形变量 `EventBits_t` 来表示一个事件组
3. 对应的位置1，表示事件发生；对应的位置0，表示事件没有发生
4. 事件组是16位表示还是32位表示，由宏 `configUSE_16_BIT_TICKS` 决定，置1，为16位，反之相反
5. 无论是16位表示还是32位表示，都是高八位存储事件组控制信息，剩余低位存储事件发生标志

## 2. 事件标志组相关API函数

FreeRTOS 提供了事件标志组的一些相关操作函数，如下表所示:

| 函数 | 描述 |
| ---- | ---- |
| xEventGroupCreate() | 使用动态方式创建事件标志组 |
| xEventGroupCreateStatic() | 使用静态方式创建事件标志组 |
| vEventGroupDelete() | 删除事件标志组 |
| xEventGroupWaitBits() | 等待事件标志位 |
| xEventGroupSetBits() | 设置事件标志位 |
| xEventGroupSetBitsFromISR() | 在中断中设置事件标志位 |
| xEventGroupClearBits() | 清零事件标志位 |
| xEventGroupClearBitsFromISR() | 在中断中清零事件标志位 |
| xEventGroupGetBits() | 获取事件组中各事件标志位的值 |
| xEventGroupGetBitsFromISR() | 在中断中获取事件组中各事件标志位的值 |
| xEventGroupSync() | 设置事件标志位，并等待事件标志位 |

### 2.1 重要函数使用

**动态创建**
函数原型如下：
```c
EventGroupHandle_t xEventGroupCreate(void); 
```
使用案例如下：
```c
EventGroupHandle_t EventGroupHandle;
EventGroupHandle =  xEventGroupCreate(); 
if (EventGroupHandle != NULL) {
    printf("事件标志组创建成功！\r\n");
}
```

**设置事件标志组**
函数原型如下：
```c
/*
    参数 xEventGroup：事件标志组的句柄
    参数 uxBitsToSet：要设置的事件位
    返回值 EventBits_t：设置后事件标志组
*/
EventBits_t xEventGroupSetBits( EventGroupHandle_t xEventGroup,
                                const EventBits_t uxBitsToSet )
```
使用案例如下：
```c
// 将低0位事件设置为1
xEventGroupSetBits(EventGroupHandle, 1 << 0);
```

**等待事件标志组**
函数原型如下：
```c
/*
    参数 xEventGroup：事件标志组的句柄
    参数 uxBitsToWaitFor：等待的事件标志位，可以用逻辑或等待多个事件标志位
    参数 xClearOnExit：成功等待到事件标志位后，清除事件组中对应的事件标志位 pdFALSE | pdTRUE
    参数 xWaitForAllBits：等待uxBitsToWaitFor 中的所有事件标志位（逻辑与） pdFALSE | pdTRUE
    参数 xTicksToWait：获取等待的阻塞时间
*/
EventBits_t xEventGroupWaitBits( EventGroupHandle_t xEventGroup,
                                 const EventBits_t uxBitsToWaitFor,
                                 const BaseType_t xClearOnExit,
                                 const BaseType_t xWaitForAllBits,
                                 TickType_t xTicksToWait )
```
使用案例如下：
```c
EventBits_t  err;
err = xEventGroupWaitBits(EventGroupHandle,         // 句柄
                                  1 << 0 | 1 << 1,  // 要等待的标志位
                                  pdTRUE,           // 等待后自动清0
                                  pdTRUE,           // 等待标志位全部满足，与
                                  portMAX_DELAY);   // 等待时间无限久
```
