# FreeRTOS软件定时器

`STM32`提供了多个硬件定时器外设，它们除了具备基本的定时器功能外，还有很多如输入捕获，产生PWM信号等强大功能。当我们只需要执行一些简单的，精确度不需要特别高的周期或者单次定时器的任务时，可以采用`FreeRTOS`提供的软件定时器。

## 1. FreeRTOS软件定时器简介

### 1.1 基本原理

在开启`FreeRTOS`的任务调度器后，内核会自动创建一个软件定时器任务（*前提是开启软件定时器的宏*）。当定时器超时时，主要由这个软件定时器任务去执行对应定时器的回调函数（*意味着可以创建多个软件定时器，数量可以很多*）。用户在其他任务中，通过提供的`API`函数来与软件定时器任务进行通信，来实现对于定时器的控制。它们之间采用**队列**来进行通信，这个队列的名称为：软件定时器命令队列。`API`的原理就是其他任务往这个队列写入控制值，软件定时器任务接收后，执行对应的函数。

用户在软件定时器的回调函数中去设置自己想要执行的周期或者定时器任务，当超时，或者受到控制时，软件定时器会执行对应的动作。

>*软件定时器的回调函数是由软件定时器任务去调用的，因此回调函数本身不是任务，不能在其内部调用如何`vTaskDelay()`、`vTaskDelayUntil()`等只能在任务中调用的函数*

### 1.2 软件定时器的状态与模式

软件定时器状态分为：**休眠态**与**运行态**，它们之间可以相互转换

软件定时器的模式分为：**单次模式**和**周期模式**

### 1.3 FreeRTOS中软件定时器的相关配置

`configUSE_TIMERS`:使能软件定时器
`configTIMER_TASK_PRIORITY`:软件定时器任务的任务优先级
`configTIMER_QUEUE_LENGTH`:软件定时器任务的命令队列长度
`configTIMER_TASK_STACK_DEPTH`:用于配置软件定时器任务栈的大小

### 1.4 FreeRTOS软件定时器相关的API函数

| 函数                        | 描述                         |
| --------------------------- | ---------------------------- |
| `xTimerCreate()`              | 动态方式创建软件定时器       |
| `xTimerCreateStatic() `       | 静态方式创建软件定时器       |
| `xTimerStart()`              | 开启软件定时器定时           |
| `xTimerStartFromISR()`        | 在中断中开启软件定时器定时   |
| `xTimerStop()`                | 停止软件定时器定时           |
| `xTimerStopFromISR()`         | 在中断中停止软件定时器定时   |
| `xTimerReset()`               | 复位软件定时器               |
| `xTimerResetFromISR()`        | 在中断中复位软件定时器       |
| `xTimerChangePeriod()`        | 更改软件定时器的定时超时时间   |
| `xTimerChangePeriodFromISR()` | 在中断中更改软件定时器的定时超时时间 |
| `xTimerDelete()`              | 删除软件定时器|
 
 ## 2.使用案例

 ```c
TimerHandle_t timer0_handle = 0;
TimerHandle_t timer1_handle = 0;

void start_task(void *pvParameters)
{
	/* 单次周期 */
	timer0_handle = xTimerCreate( "timer0", 
                                   1000,
                                   pdFALSE,
                                   0,
                                   vtimer0_callback );
	if(timer0_handle != NULL){
		printf("定时器0创建成功！！\r\n");
	}	
	
	/* 多次周期 */
	timer1_handle = xTimerCreate( "timer1", 
                                   1000,
                                   pdTRUE,
                                   0,
                                   vtimer1_callback );
	if(timer1_handle != NULL){
		printf("定时器1创建成功！！\r\n");
	}	
}

void task1(void *pvParameters)
{
	uint8_t key = 0;
    while(1)
    {
		key = key_scan(0);
		if(key == KEY0_PRES)
		{
			xTimerStart(timer0_handle, portMAX_DELAY);
			xTimerStart(timer1_handle, portMAX_DELAY);
		}
		else if(key == KEY1_PRES)
		{
			xTimerStop(timer0_handle, portMAX_DELAY);
			xTimerStop(timer1_handle, portMAX_DELAY);
		}
		vTaskDelay(10);
    }
}


void vtimer0_callback( TimerHandle_t pxTimer )
{
	static uint32_t time0 = 0;
	 /* LCD区域刷新 */ 
    lcd_fill(6, 131, 114, 313, lcd_discolor[++time0 % 11]); 
    /* 显示定时器1超时次数 */ 
    lcd_show_xnum(79, 111, time0, 3, 16, 0x80, BLUE);
	printf("time0: %d\r\n",time0);
}

void vtimer1_callback( TimerHandle_t pxTimer )
{
	static uint32_t time1 = 0;
	/* LCD区域刷新 */ 
    lcd_fill(126, 131, 233, 313, lcd_discolor[++time1 % 11]); 
    /* 显示定时器2超时次数 */ 
    lcd_show_xnum(199, 111, time1, 3, 16, 0x80, BLUE); 
	printf("time1: %d\r\n",time1);
}
 ```
